## 🌌 Overview

A custom-engineered, ultra-modern personal portfolio inspired by **Discord's "Night Terrors" popout card**, dark manga horror art, and cyberpunk HUD aesthetics. Built with pure vanilla technologies for maximum performance, 60fps physics-driven 3D parallax tilt, and millisecond-accurate audio-synced lyrics.

---

## 🩸 Killer Features

- 🎮 **Authentic Discord Profile Card** — Complete with avatar decoration, status dot, clan tags, and command terminal bio.
- 🧊 **60fps Cinematic 3D Parallax Tilt** — Physics-based LERP mouse tracking with multi-layer depth (top monster, body, and tail shift on independent spatial planes with zero font blur).
- 🌌 **Seamless Ambilight Glow** — Ambient light extracted and blurred directly from `banner.gif`, softly blooming around the entire board.
- 🔄 **Spinning Avatar Decoration** — Continuous 360° rotation with a holographic glass reflection sweep passing across the avatar every 2.5 seconds.
- 👑 **+999k High-Aura Badges** — Custom mythical badges (*Shadow Monarch, Malevolent Eye, Singularity, Soul Harvester, Infernal God*) with non-overlapping tooltips.
- 🎧 **Interactive Terminal Bio** — Styled macOS/Linux terminal with animated blinking cursor, live tech tags, and a clickable Audio mute/unmute switch.
- 🎵 **Floating Live Spotify Activity** — Synchronized real-time playback (*Starboy by The Weeknd*), interactive click-to-seek progress bar, and intelligent mute/pause sync.
- 📜 **Synced Subtitle Engine** — Real-time audio-synced lyrics rendered in clean modern typography with deep crimson and pure white punchline highlights.
- 🛡️ **Cyber HUD Anti-Theft Protocol** — Intercepts and blocks `Ctrl+U`, `F12`, and `Right-Click` with a custom security breach modal.

## ⚡ Local Setup

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/syntexwithtuhin/syntexwithtuhin.github.io.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd syntexwithtuhin.github.io
   ```
3. **Launch:**
   Simply open `index.html` in any modern web browser (Google Chrome, Brave, Firefox, or Edge).
